# Personal Portfolio — Information Technology Student

A modern, professional, responsive personal portfolio website built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS v4**. Optimized for recruiters and hiring managers.

## Features

- Sticky navigation bar with mobile hamburger menu and active-link scrollspy
- Hero section with profile photo, availability badge, CTAs, and social links
- About, Skills, Projects, Education, Experience, Certifications, Achievements, and GitHub activity sections
- Resume / call-to-action band
- Contact section with a static (mailto-based) form
- Smooth scroll, subtle reveal-on-scroll animations, and hover effects
- Mobile-first, responsive, accessible, and SEO-friendly (meta + Open Graph)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
npm run build
npm run start
```

> **Note:** On this particular machine, the native SWC binding (`@next/swc-win32-x64-msvc`) fails to load, so builds fall back to WASM. If you see a `next-swc` warning, build with webpack instead:
>
> ```bash
> npm run build -- --webpack
> ```

## Customizing Your Content

All site content lives in a single file:

```
src/data/portfolio.ts
```

Edit it to set your **name**, **title**, **email**, **GitHub/LinkedIn links**, **location**, **projects**, **certifications**, **experience**, and **achievements**.

### Assets

| File | Purpose |
| --- | --- |
| `public/images/profile.jpg` | Your profile photo (real one provided) |
| `public/images/project-*.png` | Project screenshots/thumbnails (placeholders) |
| `public/images/certificates/*.jpg` | Your certificate images |
| `public/CV.pdf` | Your resume |

The project placeholder images were generated by `scripts/generate-images.js`. The
certificate images and profile photo were copied from the `Certificates/` folder.

### Project structure

```
app/            -> Next.js App Router entry (layout + page)
src/components/ -> Section components (Navbar, Hero, About, Skills, …)
src/data/       -> portfolio.ts (single source of truth for all content)
src/lib/        -> useReveal (scroll animation hook)
public/         -> Static assets (images, CV)
scripts/        -> Build helpers
```
